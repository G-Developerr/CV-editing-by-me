## ✨ Features
- 👤 Personal info editor (name, email, phone, address)
- 💼 Work experience section (add multiple positions)
- 🎓 Education section
- 🛠️ Personal skills
- 🌍 Languages
- 💼 Portfolio section
- 🖼️ Profile image upload
- 📱 Clean responsive design

- HTML5
- CSS3
- JavaScript
